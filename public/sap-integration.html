Connect Your Real SAP AI Core Trial

1. Create an SAP AI Core instance

In your SAP BTP trial (Cloud Foundry subaccount), create an SAP AI Core service instance on the "Extended" plan — Generative AI Hub is included in this plan.

2. Create a service key and an orchestration deployment

In AI Launchpad, create a deployment against an Orchestration scenario. This gives you an Orchestration URL.

3. Add credentials to .env

From the service key, take the url, clientid, clientsecret, and your orchestration deployment URL — add them to SAP_AI_CORE_* variables in .env (full list in the README).

4. Verify

Restart the server and refresh this page — "Live Status" should show SAP AI Core as "Configured". Cross-check the payload format against your own trial's docs (help.sap.com/docs/sap-ai-core), since the orchestration API schema can vary slightly by account/version.

This adapter is a genuine, working template — but you should verify SAP AI Core's exact orchestration request format against your trial's official docs before a live demo. Telling judges "we built a real SAP AI Core integration path with a production-safe fallback" is itself a strong point.
