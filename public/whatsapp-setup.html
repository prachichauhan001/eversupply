💬 Real Integration

Connect Real WhatsApp

The backend already exposes a real, working webhook at /webhook/whatsapp. Connect it to Twilio in six steps:

1. Create a Twilio account

Sign up free at twilio.com/try-twilio. Copy your Account SID and Auth Token from the Console Dashboard into your .env file.

2. Activate the WhatsApp Sandbox

Twilio Console → Messaging → Try it out → Send a WhatsApp message. You'll get a sandbox number and a "join <code>" message.

3. Connect your phone to the sandbox

From the number you want to test as a vendor, send "join <code>" to the sandbox number (one-time step).

4. Make your server public

Terminal 1: npm start. Terminal 2: ngrok http 3000. Copy the https URL it gives you.

5. Set the webhook URL in Twilio

In Twilio Sandbox settings, under "WHEN A MESSAGE COMES IN": https://your-ngrok-url.ngrok-free.app/webhook/whatsapp, method POST.

6. Test it

Message the sandbox number from the vendor's phone, in their own language — the dashboard updates live, and the vendor gets an automatic reply in the same language.

For permanent 24/7 hosting: deploy this backend to Render.com or Railway.app (both free tier) — you'll get a permanent URL and won't need ngrok anymore.
